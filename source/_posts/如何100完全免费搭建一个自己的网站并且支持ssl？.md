## 域名

1.[freenom](https://www.freenom.com/)  我们首先到网站主页

![](https://b2.kuibu.net/file/imgdisk/imgs/2021/11/ce32fdc834fc77e9.png)

在搜索框搜索你喜欢的名字，我这里以“xiangda”为例。

搜索之后就可以选择你想要的域名了，因为我们要白嫖，所以我们选择.tk.ml.ga.cf.gq后缀的域名。

![](https://b2.kuibu.net/file/imgdisk/imgs/2021/11/0e79198be76e48df.png)

因为我们没有登录所以这里显示不可用是正常的，我们直接在搜索框搜索你想要的域名，我以“xiangda.ml"为例。

我们直接选择加入购物车。

![](https://b2.kuibu.net/file/imgdisk/imgs/2021/11/4cc1aaa127726eae.png)

这里是购物车界面，为了最大程度白嫖我们不要选默认的三个月，直接12个月走起！

![](https://b2.kuibu.net/file/imgdisk/imgs/2021/11/1905525c628c0505.png)

点击继续就来到了最后的结算界面，注意这里需要邮箱验证，建议用国外邮箱。

![](https://b2.kuibu.net/file/imgdisk/imgs/2021/11/6aaa61032a2f6d95.png)

验证邮箱。

点击验证后，你就收收到一封邮件验证，登陆邮箱验证后，你必须填写一些基本信息并设置密码，部分截图如下：

![填写用户信息](https://coderschool.cn/wp-content/uploads/2017/03/freenom5.png)

信息填完成，点击完成订购按钮，这时候系统会再给你发一封确认订购的邮件，你需登陆邮箱完成确认订购。确认完成后你用上面设置的账户进行登陆，登陆后点击右上角的 service 选项下的 My Domians：

![选择我的域名选项](https://coderschool.cn/wp-content/uploads/2017/03/freenom6.png)

这时候你就会看到域名是激活、免费的状态，说明你已经成功的申请了该域名：

![我的域名列表](https://coderschool.cn/wp-content/uploads/2017/03/freenom7.png)

freenom域名解析 在上图你的域名列表中，最右侧有个 Manage Domain（管理域名选项），你点击该选项，就可以进入域名管理界面：

![设置域名dns服务](https://coderschool.cn/wp-content/uploads/2017/03/freenom8.png)

然后在 Management Tools 选项下选择 nameservers，系统默认使用的是 freenom 自己默认的 dns 服务器。你可以设定其他的dns服务器。 这里我使用默认的 dns 服务器，先不做修改。然后点击右侧的 Manage Freenom DNS 选项，给自己的域名绑定ip 比如：

![设置域名A记录等](https://coderschool.cn/wp-content/uploads/2017/03/freenom9.png)

在 target 选项输入你域名要绑定的 ip ，在 Name 选项输入 www 或其它子域名，type 你可以根据需要进行选择。当保存成功后，你就可以直接输入域名访问你的站点了。

## 虚拟主机

在infinityfree上注册账号。

[infinityfree](https://infinityfree.net/)

![](https://z3.ax1x.com/2021/11/20/IOw9qf.png)

注册非常简单，输入邮箱和密码即可，我这里已经注册过了，就不多做演示了。

![](https://z3.ax1x.com/2021/11/20/IOwHln.png)

这里需要注意的是，该网站有谷歌验证，需要魔法上网。

![](https://z3.ax1x.com/2021/11/20/IO0a1s.png)

这里就是登录成功后的用户主页。

我们点击Create Account创建网站。

![](https://z3.ax1x.com/2021/11/20/IOB129.png)

可以选择二级域名前缀或者用自己的域名，你随意，我暂时选择二级域名。

其余按照内容填写就行了，很快啊。

![](https://z3.ax1x.com/2021/11/20/IOB5xs.png)

![](https://z3.ax1x.com/2021/11/20/IOBbZV.png)

这里是网站管理界面，数据库，ftp账号密码都有的

点击大大的ControlPanel，进入网站面板。

![](https://z3.ax1x.com/2021/11/20/IOrkmq.png)

DOMAINS这一栏，到这里绑定域名。

![](https://z3.ax1x.com/2021/11/20/IO2E7R.png)

![](https://z3.ax1x.com/2021/11/20/IORnVs.png)

将网站绑定你自己的域名。

回到freenom，修改dns服务器

![](https://z3.ax1x.com/2021/11/21/IXwiAU.png)

把域名的服务器修改为:

```
ns1.epizy.com
ns2.epizy.com
```

稍等片刻，添加域名即可成功！

往下滑找到SOFTWARE,点击softaculous apps installer，安装应用，我这里以WordPress为例，直接安装。

![](https://z3.ax1x.com/2021/11/20/IOrH4U.png)

![](https://z3.ax1x.com/2021/11/20/IOrxD1.png)

install now！直接安装！

这里选择网站设置，标题，账号密码之类的~

![](https://z3.ax1x.com/2021/11/21/IXwnnx.png)

记住这里要选择你刚添加的域名。

不要忘了把语言选择为中文。

![](https://z3.ax1x.com/2021/11/20/IOsB24.png)

最后安装。

wordpress安装好后，到外观-主题，添加喜欢的主题就行了。

![](https://z3.ax1x.com/2021/11/20/IO6Ogg.png)

到这里已经完成所有操作，访问[祥达博客 – xiangda‘blog](http://xiangda.ml/?i=1)查看网站建设成功！

![](https://z3.ax1x.com/2021/11/21/IXw45F.png)

## SSL

返回到面板主页，找到SECURITY-SSL

![](https://z3.ax1x.com/2021/11/26/oZJStH.png)

可以在这里选择要添加ssl的域名

![](https://z3.ax1x.com/2021/11/26/oZJAnf.png)

我就以我白嫖的xiangda.ml域名为例，来申请ssl

![](https://z3.ax1x.com/2021/11/26/oZJg4H.png)

![](https://z3.ax1x.com/2021/11/26/oZJ5KP.png)

直接在这样输入私匙证书就行了，如果没有可以直接免费申请

[到这里申请ssl](https://app.infinityfree.net/sslCertificates)

![](https://z3.ax1x.com/2021/11/26/oZYUZ8.png)

![](https://z3.ax1x.com/2021/11/26/oZYtqf.png)

![](https://z3.ax1x.com/2021/11/26/oZYadS.png)

输入域名， 选择 SSL 提供商。我选择Let's Encrypt。

在你的域名上设置以下 CNAME 记录。此记录对于证书提供商证明您拥有域名是必要的。

![](https://z3.ax1x.com/2021/11/26/oZNd3j.png)

再次回到面板，在这里可以设置 CNAME 记录。

![](https://z3.ax1x.com/2021/11/26/oZUZMn.png)

在这里输入相应的数值即可，我已经完成了。

![](https://z3.ax1x.com/2021/11/26/oZUMIU.png)

下面就是成功了的界面，如果一切操作正常那么一点会成功的。

![](https://z3.ax1x.com/2021/11/26/oZUcLt.png)

在这里展开查看证书和密匙

![](https://z3.ax1x.com/2021/11/26/oZUWo8.png)

![](https://z3.ax1x.com/2021/11/26/oZUxW4.png)

再把证书密匙复制到这里来

![](https://z3.ax1x.com/2021/11/26/oZJg4H.png)

输入密匙，点击上传密匙即可，证书也是

![](https://z3.ax1x.com/2021/11/26/oZaNlj.png)

最后回到网站xiangda.ml

可以看到已经支持HTTPS了

![](https://z3.ax1x.com/2021/11/26/oZw6y9.png)
